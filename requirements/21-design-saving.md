# الحفظ الذري والتلقائي للتصميم

تاريخ التنفيذ: 2026-09-09.

## ما تم تنفيذه

- مسار خاص `PATCH /app/events/{event}/design` لا يقبله إلا مالك المناسبة النشط.
- `SaveDesignRequest` يرفض خصائص الجذر غير المعروفة، ويتحقق من حجم الوثيقة قبل تحويلها.
- `DesignDocumentHydrator` يحول كل قسم إلى DTO صارم ويرفض الحقول الناقصة أو الإضافية والأنواع غير المطابقة.
- رفض markup وروابط JavaScript داخل النص، وعدم وجود أي حقل يقبل URL خارجياً للأصول.
- التحقق من وجود كل أصل وإصداره ونوع استخدامه، ورفض إضافة أصل متوقف لم يكن موجوداً سابقاً في التصميم.
- `SaveDesignAction` يقفل سجل التصميم داخل transaction، ويقارن `expectedRevision`، ويحفظ البطاقة واللوحة والمشهد معاً ثم يزيد revision مرة واحدة.
- تعارض revision يعيد HTTP 409 مع snapshot الحالية، ولا يكتب فوقها.
- الحفظ التلقائي ينتظر 900ms، ويرتب الطلبات المتلاحقة، ويعيد حفظ أحدث تعديل بعد انتهاء الطلب الجاري.
- حالات واجهة واضحة: محفوظ، بانتظار الحفظ، جارٍ الحفظ، دون اتصال، خطأ، وتعارض.
- عند التعارض يبقى العمل المحلي ظاهراً ويختار المستخدم صراحة تحميل نسخة الخادم أو الاحتفاظ بتعديلاته فوقها.
- تحذير المتصفح عند محاولة إغلاق الصفحة وفيها تعديل غير محفوظ، وإعادة المحاولة تلقائياً عند رجوع الاتصال.

## الحماية

لا يقبل endpoint أي حقول استحقاق مثل `is_paid`، ولا يعيد مسارات SVG الخاصة. تعطيل العلامة المائية الحالي قرار مؤقت سابق من المستخدم؛ لذلك يبقى البند 08.06 مفتوحاً ولا يوصف كمنفذ.

## التحقق

- حفظ وثيقة كاملة واسترجاعها بعد إعادة تحميل صفحة المحرر.
- زيادة revision من 1 إلى 2 في قاعدة التطوير.
- اختبار stale revision يعيد snapshot الأحدث دون استبدالها.
- اختبارات ملكية، خصائص مجهولة، HTML، حقول خادم، أصل مفقود، إصدار خاطئ، نوع خاطئ، وأصل متوقف.
- نجح فحص Laravel الكامل: 76 اختباراً و720 تحققاً.
- نجحت 14 حالة للواجهة، وفحص TypeScript الصارم، وبناء Vite الإنتاجي.
