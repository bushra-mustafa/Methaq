# تأسيس التطبيق والحسابات

اكتملت المرحلة 03 بتاريخ 2026-09-09. تعتمد المصادقة على جلسات Laravel وFortify بواجهات React/Inertia عربية، ولا يوجد REST API مستقل للحسابات.

## ما تم تنفيذه

- تسجيل ودخول وخروج واستعادة وتغيير كلمة المرور والتحقق من البريد.
- تسجيل العميل دائماً بقيمتي `customer` و`active` من الخادم، مع تجاهل أي محاولة لإرسال `role` أو `status` من النموذج.
- ملف حساب لتعديل الاسم والبريد والهاتف؛ تغيير البريد يلغي التحقق السابق ويرسل رابطاً جديداً.
- جلسات محفوظة في قاعدة البيانات ومشفرة، مع عرض الأجهزة وتسجيل خروج الجلسات الأخرى بعد تأكيد كلمة المرور.
- رفض الحساب المعلّق عند الدخول وإبطال جلسته عند كل طلب محمي، وعدم مشاركته ضمن Inertia props بعد التعليق.
- ردان متطابقان لاستعادة كلمة المرور للبريد الموجود وغير الموجود لمنع كشف الحسابات المسجلة.
- حد محاولات للدخول ولتحدي التحقق بخطوتين.
- تحقق بخطوتين مع تأكيد الرمز ورموز استرداد مشفرة؛ صفحات الإدارة تشترط مديراً نشطاً أتم تفعيل التحقق بخطوتين.
- أمر تشغيل موثوق `methaq:promote-admin` لترقية مستخدم نشط موجود، مع سجل تدقيق داخل المعاملة نفسها.
- Policies أولية للمستخدمين والمناسبات والقوالب. المدير لا يحصل على تجاوز عام لملكية مناسبة العميل.
- cookie خاص بالمضيف دون مشاركته مع النطاقات الفرعية، مع `HttpOnly` و`SameSite=Lax` ودعم `Secure` في الإنتاج.
- تخزين محلي خاص افتراضياً، queue بقاعدة البيانات بعد نجاح المعاملة، وملفات إعداد نموذجية بلا أسرار.
- فحص GitHub Actions للتنسيق والأنواع وعقود الواجهة والبناء واختبارات MySQL.

## حدود المرحلة

لوحة الإدارة الحالية تثبت بوابة الوصول فقط. إدارة المستخدمين وتعليقهم وإدارة القوالب تنفذ في المرحلتين 05 و06، والدفع باقٍ للمرحلة 14. لا توجد بيانات مدير ثابتة داخل seeder ولا مسار واجهة لترقية الدور.

## التحقق

- `php artisan test -c phpunit.mysql.xml`: نجح 43 اختباراً و175 تحققاً على قاعدة تنتهي بـ `_test`.
- `npm run typecheck`: نجح دون `any`.
- `npm run test:frontend`: نجحت 10 اختبارات لعقود التصميم والنموذج المرجعي.
- `npm run build`: نجح بناء Vite الإنتاجي.
- `vendor/bin/pint --test` و`composer validate --strict`: نجحا.
- تمت معاينة صفحة الدخول فعلياً بعرض سطح المكتب والهاتف دون أخطاء متصفح.

## نقاط الدخول

| المسار | الغرض |
|---|---|
| `/register` | إنشاء حساب عميل |
| `/login` | تسجيل الدخول وتحدي التحقق بخطوتين عند تفعيله |
| `/forgot-password` | طلب رابط الاستعادة برسالة لا تكشف وجود البريد |
| `/email/verify` | التحقق من البريد |
| `/app` | لوحة مناسبات المستخدم |
| `/app/profile` | بيانات الحساب وكلمة المرور والجلسات والتحقق بخطوتين |
| `/app/admin` | أساس لوحة الإدارة المحمي بالدور والتحقق بخطوتين |

يبقى `/dev/design-lab` متاحاً في البيئة المحلية فقط ولا يظهر رابطُه في الإنتاج.
