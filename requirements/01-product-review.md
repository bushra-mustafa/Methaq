# مراجعة المنتج

> تحديث 2.0: راجع [المخطط الشامل الجديد](09-methaq-master-plan-v2.md) قبل التنفيذ. يتقدم على هذا الملف عند التعارض، خصوصاً مكتبة العناصر المشتركة والمشهد التفاعلي والجداول ودورة نشر النسخة المطلوبة.

## المتطلبات المعتمدة من المستخدم

ميثاق منصة إنشاء بطاقات ودعوات للزفاف والتخرج. محرر Mix & Match يستخدم Fabric.js v6، يحفظ JSON، ويعرض قبل الدفع معاينة منخفضة الدقة بعلامة مائية ديناميكية. الدفع الموثق يفعل النشر على نطاق فرعي، ويتيح نسخة نهائية بلا علامة مائية. الضيوف يرسلون RSVP. ينتهي الرابط بعد عشرة أيام من موعد المناسبة.

التقنيات: Laravel 12، PHP 8.3+، React 19، TypeScript strict، Inertia.js v2، MySQL. لا Next.js ولا REST API منفصل في نطاق هذا الإصدار. تطبيق Flutter ليس ضمن PRD الحالي.

## نتيجة المراجعة

الجداول السبعة صحيحة كأساس، لكنها وحدها لا تحدد نظاماً جاهزاً للإنتاج. النواقص وطرق تغطيتها:

| النقص | الاستكمال المقترح |
|---|---|
| القالب بلا بيانات Canvas | default_design_json وschema_version في templates |
| الأصول مشتركة بين القوالب | أصول مستقلة وجدول template_asset_links متعدد إلى متعدد |
| تكرار إشعارات بوابة الدفع | payment_webhooks مع مفتاح فريد ومعالجة قابلة للإعادة |
| فقدان مهمة التصدير بعد تثبيت الدفع | design_renders كسجل عمل دائم يعاد التقاطه |
| وصول حفظ قديم فوق حفظ أحدث | revision ومقارنة ذرية عند الحفظ |
| نشر تعديل غير جاهز | فصل design_revision عن published_revision |
| timezone وحدود الانتهاء | تخزين UTC وحساب عشرة أيام تقويمية بمنطقة المناسبة |
| رابط نهائي يظل مفتوحاً بعد الانتهاء | تخزين خاص وتحقق عند تسليم المحتوى؛ لا URL عام دائم |
| تأخير Cron | Middleware يتحقق من expires_at في كل زيارة وRSVP |
| تعدد محاولات الدفع | orders متعددة للمناسبة؛ كل محاولة لها idempotency_key |
| حفظ RSVP مكرر بسبب إعادة المحاولة | submission_token فريد داخل المناسبة |

## حدود الإصدار الأول المقترحة

داخل النطاق: حسابات، قوالب وأصول يديرها فريق التشغيل، مناسبات، محرر وحفظ تلقائي، دفع ونشر، تصيير، نطاقات فرعية، RSVP، انتهاء، مراقبة تشغيلية أساسية.

مؤجل: رفع أصول من العملاء، دعوات خاصة برمز لكل ضيف، تحقق هاتف OTP، تعاون فوري، بيع اشتراكات، أكثر من باقة، متجر قوالب، تطبيق جوال، وواجهة إدارة محتوى متكاملة. لا يمنع التأجيل تجهيز واجهات توسع واضحة.

## حدود الحماية

العلامة المائية والدقة المنخفضة تقللان جودة النسخ، ولا تمنعان تصوير الشاشة أو تعديل JavaScript. الأصول الأصلية والتصدير النهائي لا يرسلان لغير المستحقين. لا يوصف المنتج بأنه يمنع السرقة بالكامل. الدعوة المدفوعة العامة قابلة للمشاهدة والنسخ بطبيعتها.
