# التجربة المرجعية الأولى — 2026-09-09

المسار المحلي: `/dev/design-lab`. يعيد 404 خارج بيئتي local/testing. لا يحتاج حساباً لأنه نموذج تطوير معزول؛ لا يُستخدم كمسار تحرير مناسبات حقيقية.

## المنفذ

- بطاقة Fabric v6 بمقاس منطقي 1080×1920 ومعاينة فعلية 360×640 دون مضاعفة Retina.
- تغيير لون الخلفية والنص والإطار واللمعة بصورة مستقلة؛ خلفية بودرية افتراضية.
- أسماء عربية بأميري أو إنجليزية بـPinyon Script، دعاء بأميري وموعد بتجوال؛ الخطوط محلية مع OFL.
- تحريك النصوص بالسحب أو أزرار رفع/خفض ذات أسماء عربية لقارئات الشاشة.
- مؤثر لمعة CSS مستقل عن بيانات Canvas، مع شدة وإيقاف حركة واحترام prefers-reduced-motion في CSS.
- معاينة ظرف مبسط بلون البطاقة وختم «م»، وفتح البطاقة وإعادة عرض الظرف.
- حفظ واستعادة محليان لبيانات إصدار 2 مع قبول وترقية الإصدار 1، مع التحقق من الحقول والألوان والحدود والمواضع قبل قبولها.
- زر تصدير يعرض PNG الناتج داخل الصفحة مع رابط حفظ ووسيلة إغلاق؛ الصورة ثابتة منخفضة الدقة بعلامة مائية داخل Canvas، ولا تتضمن اللمعة المتحركة.

## الفصل المعماري

الصفحة `Pages/App/DesignLab.tsx` تجمع لوحة الخيارات والمعاينة، ويعزل `usePrototypeCanvas` دورة حياة Fabric والخطوط والتصدير. عقد البيانات في `Types/PrototypeDesign.ts` والتحقق في `Domains/Editor/Services/prototypeDesign.ts`. Controller يعيد صفحة Inertia فقط؛ Middleware يقيّد الوصول بالبيئة.

عقد PrototypeDesign تجريبي محدود، وليس بديلاً عن DesignDocument الإنتاجي المخطط للمرحلة 02. لا يرسل Fabric JSON خاماً للخادم، ولا يتعامل مع حقول الدفع أو النشر.

## التحقق

- `npm run typecheck`: ناجح.
- `npm run test:prototype`: 5 اختبارات تشمل الدوران حفظاً واستعادة، رفض المدخلات غير الصالحة وإسقاط الحقول الزائدة. الأمر يستعمل دعم TypeScript التجريبي في Node المحلي 23؛ يحتاج بيئة Node داعمة له.
- اختبارات Laravel المحددة للصفحة وبروتوكول Inertia وربط المستخدم: 6 اختبارات و30 assertion ناجحة.
- Pint: ناجح.
- فحص متصفح: الحفظ والتعديل والاستعادة، التبديل للعربية، فتح الظرف، وعرض أدوات التحكم بعرض 390px. لم تظهر أخطاء في سجل المتصفح أثناء الفحص.
- فُحصت بيانات PNG الفعلية المعروضة بعد التصدير بصرياً بمقاس 360×640: أسماء إنجليزية ودعاء وتاريخ عربيان وخلفية بودرية وإطار وعلامة مائية. عرض الصورة ورابط الحفظ متاحان داخل الصفحة. التحقق الشامل لكل أوضاع اللغة والخطوط ما زال مفتوحاً.

## الحدود والخطوة التالية

التجربة لا تمثل محرراً إنتاجياً: لا حفظ خادمي أو autosave أو سجل تراجع أو مكتبة عناصر أو صور أو صوت أو دخان أو نشر. النصوص الطويلة تحتاج لاحقاً قواعد احتواء وتوزيع. لون الظرف والختم وطريقة الدخول أصبحت مستقلة وقابلة للحفظ.

العلامة المائية في المتصفح وسيلة معاينة فقط، ويمكن تجاوزها من جهة العميل؛ حماية الأصول والتصدير المدفوع يجب فرضها على الخادم في مراحلها. لا توجد أصول نهائية مدفوعة في هذه التجربة.

قبل إغلاق المرحلة 01: استكمال فحص تقليل الحركة على الهاتف وحصر بقية الأصول ورخصها. بعدها تثبيت عقود التصميم والمشهد الإنتاجية قبل بناء محرر المناسبات. الدفع يبقى آخر مرحلة برمجية وفق قرار المستخدم.

## مطابقة التكوين المرجعي بعد ملاحظة المستخدم

- `ReferenceInvitation`: معاينة dialog بملء الشاشة، ظرف بودري متعدد الطبقات، ختم قابل للتغيير، خروج ورقة ثم ظهور البطاقة بعد 1700ms، إعادة الفتح، تجاوز المقدمة، وإيقاف الحركة. Escape والرجوع يغلقان المعاينة؛ ينتقل التركيز إلى عنوان الدعوة بعد الفتح.
- `referenceArtwork`: قوس وإطار مزدوج وزهور وخواتم داخل Fabric، بحيث تشملها صورة PNG. ورق البطاقة والمشهد والحبر والزخارف والظرف أدوار لونية مستقلة. زخارف Flower2 وLeaf من Lucide المستخدم في المرجع؛ رخصة ISC/Feather المرافقة في resources/brand/licenses/lucide.txt. لا توجد صور أو موسيقى منقولة مجهولة الرخصة.
- `ReferenceAtmosphere`: توزيع اللمعة المداري مقتبس من معادلات المرجع العنابي مع لون وشدة مستقلين، دون الصورة العنابية أو WebGL الدخان. يراعي إيقاف الحركة وprefers-reduced-motion وإخفاء الصفحة ويزيل المؤقتات والمراقبين عند الإغلاق.
- الأسماء الإنجليزية عمودية بـPinyon Script والعربية بأميري. احتواء ارتفاع النصوص الأساسية بتصغير الخط عند تجاوز الحدود؛ الحدود لا تعوض أدوات التنسيق الكاملة القادمة.
- البيانات أصبحت إصدار 2 ومفتاح حفظ جديد؛ يمكن استعادة إصدار 1 دون فقد نصوصه ومواضعه، وتضاف إليه إعدادات المشهد الافتراضية. مفتاح الإصدار القديم لا يمسح.
- فحص بصري للظرف ثم البطاقة، وتصدير PNG بالعربية مع القوس والزهور والإطار والعلامة المائية. لا أخطاء متصفح أثناء فحص الفتح. لا ادعاء بإكمال مكتبة القوالب أو مشهد الصوت/الدخان أو الحفظ الخادمي.
