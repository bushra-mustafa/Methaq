# 25. دعوة الضيف وتأكيد الحضور

## الفصل بين المسارين

- صاحبة المناسبة تعمل من لوحة الحساب: محرر البطاقة ثم صفحة الظرف والحركة والصوت، مع معاينة كاملة قبل الإطلاق.
- الضيف لا يرى أدوات التحرير أو بيانات طبقات التصميم. يرى الظرف، حركة الفتح، الصوت الاختياري، البطاقة النهائية، ثم نموذج RSVP فقط.

## الرابط العام

- الرابط هو `subdomain.METHAQ_INVITATION_DOMAIN`.
- محلياً القيمة الافتراضية هي `methaq.test`، وفي الإنتاج تصبح `methaq.link`.
- `ResolvePublishedEvent` لا يسمح إلا بمناسبة حالتها `published` وغير منتهية. المسودة أو الرابط المنتهي يرجعان 404.
- العرض العام يعتمد على `final_render_path` ونسخة المشهد والألوان المنشورة؛ لا يرسل JSON محرر البطاقة إلى الضيف.

## RSVP

- الاسم وحالة الحضور مطلوبان؛ الهاتف والرسالة اختياريان.
- عدد المرافقين بين 0 و20، ويثبت تلقائياً على 0 عند الاعتذار.
- لكل متصفح رمز إرسال UUID؛ إعادة الإرسال بالرمز نفسه تصحح الرد الموجود بدلاً من إنشاء رد مكرر.

## الإطلاق والدفع

واجهة صاحبة المناسبة تسمح بالتعديل والمراجعة الآن. التحويل إلى `published` وتكوين النسخة النهائية يبقيان ضمن خطوة الدفع والنشر الأخيرة، لأن قاعدة البيانات تمنع نشر مناسبة غير مدفوعة.
