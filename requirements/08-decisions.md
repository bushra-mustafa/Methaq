# سجل القرارات

> تحديث 2.0: راجع [المخطط الشامل الجديد](09-methaq-master-plan-v2.md) قبل التنفيذ. يتقدم على هذا الملف عند التعارض، خصوصاً مكتبة العناصر المشتركة والمشهد التفاعلي والجداول ودورة نشر النسخة المطلوبة.

## ثابت بطلب المستخدم

- Modular DDD؛ فصل Http وInfrastructure؛ Actions وServices وDTOs؛ SOLID.
- Laravel 12 وPHP 8.3+ وReact 19 وInertia.js v2 وFabric.js v6 وMySQL.
- Pay-to-Publish؛ علامة مائية ومعاينة منخفضة الدقة؛ نطاق فرعي فريد.
- صلاحية حتى عشرة أيام بعد المناسبة، وحالات draft/published/expired.
- نطاقات Events وEditor وPayments وRSVP وهيكل المجلدات الأساسي.

## استكمال مقترح يحتاج تثبيتاً قبل الجزء المعني

| القرار | الافتراض المقترح | متى يلزم الحسم |
|---|---|---|
| ردود Controllers | Inertia للصفحات؛ redirect للحفظ؛ acknowledgment للـ webhook وملف للتصيير | قبل المسارات |
| جدول الأصول | مكتبة مستقلة مع جدول ربط للقوالب | قبل migrations |
| موثوقية المهام | payment_webhooks وdesign_renders دائمان | قبل migrations |
| عرض الضيوف — محسوم في 2.0 | بطاقة Fabric مصيّرة داخل مشهد React تفاعلي للظرف والمؤثرات والصوت وRSVP | معتمد بطلب المستخدم الأخير |
| تعديل منشور | مسودة ثم زر تحديث؛ الصورة السابقة تبقى حتى نجاح التصيير | قبل المحرر المدفوع |
| تعديل موعد/نطاق بعد الدفع | تجميدهما مبدئياً | قبل تحديث المناسبة |
| معنى الأيام العشرة | أيام تقويمية في منطقة المناسبة | قبل CreateEventAction |
| إنشاء الحساب | مطلوب قبل إنشاء/حفظ مناسبة؛ تصفح القوالب عام | قبل auth |
| سعر وعملة وبوابة | إعداد خادم؛ لا سعر أو عملة إنتاجية مفترضة | قبل Checkout |
| استقبال دفع بعد الانتهاء/دفعتين | توثيق وتدخل تسوية، بلا إعادة فتح تلقائي | قبل الدفع الإنتاجي |
| إلغاء/استرجاع/نزاع | غير محدد؛ statuses الحالية لا تغطي refund | قبل إطلاق الدفع؛ إضافة refund model/حقول عند اعتماد السياسة |
| الاحتفاظ والحذف | لا حذف تلقائي عند انتهاء الرابط | قبل الإطلاق وسياسة الخصوصية |
| RSVP | مفتوح لحامل الرابط؛ بلا تحقق هوية أو تعديل لاحق | قبل RSVP |
| الهوية البصرية | عربي RTL، لم يحدد شعار أو ألوان أو خط | قبل التصميم البصري النهائي |

لا يعد وجود اقتراح في هذه الحزمة موافقة مستخدم عليه. يمكن بناء الأساس غير المعتمد على هذه الخيارات، ويعرض القرار المعني قبل تثبيت السلوك المختلف عن نص المستخدم.
