# تصميم الشاشات وظيفياً

> تحديث 2.0: راجع [المخطط الشامل الجديد](09-methaq-master-plan-v2.md) قبل التنفيذ. يتقدم على هذا الملف عند التعارض، خصوصاً مكتبة العناصر المشتركة والمشهد التفاعلي والجداول ودورة نشر النسخة المطلوبة.

هذه مواصفات UX وتخطيطات أولية نصية، وليست تصميماً بصرياً نهائياً. افتراض الإصدار الأول: واجهة عربية RTL، مع اختبار الخط العربي وتشكيله في Fabric وفي ناتج التصدير. الألوان والخط والشعار تحتاج هوية معتمدة.

## صفحات التطبيق

| الشاشة | المحتوى والإجراء | الحالات المطلوبة |
|---|---|---|
| الرئيسية | تعريف ميثاق، قوالب زفاف/تخرج، خطوات الخدمة، ابدأ التصميم | تحميل القوالب، فارغة، تعذر التحميل |
| التسجيل/الدخول | اسم، بريد، كلمة مرور؛ الهاتف اختياري | تحقق، خطأ، إعادة تعيين، نجاح |
| لوحة المناسبات | بطاقات: العنوان، الموعد، الحالة، صلاحية الرابط | لا مناسبات + أنشئ مناسبة، تحميل، خطأ |
| إنشاء مناسبة | اختيار قالب، عنوان، موعد ومنطقة زمنية، معاينة slug | قالب غير متاح، تاريخ غير صالح |
| المحرر | Canvas، الأصول، الطبقات، النصوص، تراجع/إعادة، حالة حفظ | جاري الحفظ، محفوظ، فشل، تعارض، انقطاع اتصال |
| الدفع | مبلغ وعملة من الخادم، ملخص المناسبة والصلاحية، زر ادفع وانشر | pending، failed، cancelled لدى البوابة، confirmed |
| النشر | الرابط، نسخ الرابط، حالة تجهيز النسخة | preparing، ready، render failed + إعادة محاولة |
| الحضور | أسماء وحالة ومرافقون وملاحظات، إجمالي المؤكدين | فارغة، تحميل، خطأ؛ خاصة بالمالك |
| دعوة الضيف | التصميم المنشور، الموعد، نموذج RSVP | تجهيز، غير موجود، منتهي، تعذر تحميل |
| تأكيد RSVP | تأكيد التسجيل دون كشف ردود آخرين | تحقق، إرسال، إعادة محاولة، نجاح |

## تخطيط المحرر

```text
[ميثاق] [عنوان المناسبة] [حالة الحفظ] [معاينة] [ادفع وانشر / تحديث المنشور]
[أصول وقوالب]       [مساحة Canvas قابلة للتكبير]       [طبقات وخصائص]
                   [تراجع] [إعادة] [نسبة التكبير]
```

على الهاتف: مساحة العمل أولاً، أدوات في شريط سفلي وخصائص في لوحة قابلة للفتح. العلامة المائية ليست طبقة قابلة للحذف. ترتيب الطبقات قابل للتحكم بلوحة المفاتيح والأزرار، وليس السحب وحده. التحذير عند مغادرة مسودة غير محفوظة، وعدم إظهار «محفوظ» قبل إقرار الخادم.

## تخطيط دعوة الضيف

```text
[التصميم المنشور]
[عنوان المناسبة — الموعد والمنطقة الزمنية]
[الاسم] [الهاتف اختياري]
[سأحضر / أعتذر / ربما]
[عدد المرافقين] [رسالة اختيارية]
[تأكيد الرد]
```

الحد الأدنى للتفاعل هو RSVP. الموقع والخريطة والموسيقى والعد التنازلي ليست ضمن البيانات الأصلية؛ لا تعد وظائف منفذة. إضافة وصف نصي للدعوة خارج الصورة يتيح قراءة العنوان والموعد بالتقنيات المساعدة. جميع الأزرار لها تسميات واضحة وحالات focus ورسائل validation قرب الحقول؛ لا يعتمد معنى الحالة على اللون وحده.
