# هوية ميثاق المستوردة

المصدر: مجلد methaq-brand الذي قدمه المستخدم بتاريخ 2026-09-09. الشعار الأساسي من الحزمة الرئيسية: الاسم العربي والإنجليزي مسارات SVG، مع النسخ المسطحة والعكسية والمبسطة.

## الاستخدام

- شريط الموقع: /brand/logos/methaq-horizontal-compact-flat.svg؛ عرض إرشادي أدنى 240px.
- الخلفية الخضراء: النسخة compact-reverse-gold أو compact-white.
- عرض أكبر: methaq-vertical-flat.svg؛ عرض إرشادي أدنى 192px.
- التسويق: methaq-marketing-flat.svg؛ عرض إرشادي أدنى 280px.
- favicon وApple touch icon: public/brand/icons، جاهزة للربط في layout عند بناء الواجهة.
- PNG شفافة بديلة: public/brand/images.
- وصف الشعار البديل: «ميثاق — Methaq»؛ الحفاظ على النسب والمساحة الآمنة في الدليل.

الألوان في palette.json تطابق ملفات الشعار الرئيسية: الأخضر #074B36، الذهبي #B69A50، العاجي #F5F2E3. لا نخلط معها قيم identity-v1 المختلفة.

خطا Noto Sans Arabic وManrope مستوردان من identity-v1 مع رخصتي OFL ومصدرهما. هذه خطوط للنصوص وليست الخط الأصلي للشعار. تعريفاتهما والألوان جاهزة في resources/css/brand.css، ولم تربط بصفحة Laravel الترحيبية المؤقتة. يستورد ملف CSS عند بناء layout المنصة؛ لا يتم تحميل خطوط خارجية لهذا الغرض.

لم تنقل البدائل الرمزية المختلفة أو الأنماط المشتقة منها، ولا ملفات ZIP أو سكربتات التوليد أو صور المعاينة الكبيرة أو قوالب الطباعة. لم تعدل الملفات الأصلية. لا توجد صور مناسبات مستقلة ضمن الاختيارات الحالية؛ صور PNG المستوردة نسخ للشعار فقط.

مصادر الأصول ومساراتها وبصماتها في manifest.json. اختيار الهوية هنا إعداد عملي بناءً على طلب المستخدم، ويمكن تبديل الحزمة إذا اختار رمز identity-v1 لاحقاً. ألوان منصة ميثاق لا تقيد ألوان دعوات العملاء.
